# MNC Review Copilot 🚀

> An AI-powered, zero-friction performance review copilot designed for managers in multinational corporations. Transform raw, unstructured observations into polished, objective, and STAR-compliant corporate communications in seconds.

![Stack](https://img.shields.io/badge/Stack-Single%20File%20HTML%20%2B%20TailwindCSS-indigo?style=flat-square)

---

## ✨ Features

* **Zero-Friction Architecture**: Built as a lightning-fast, single-file HTML deployment with zero complex build steps or server-side overhead.
* **Multi-Tone Frameworks**: Tailor your feedback instantly across 3 professional registers:
  * **Executive Professional**: High-level strategic framing for leadership alignment.
  * **Constructive Growth-Oriented**: Balanced, developmental feedback structured around the STAR method.
  * **High-Impact Excellence Praise**: Exceptional recognition and positive reinforcement.
* **STAR Methodology Alignment**: Automatically structures rough notes into Situation, Task, Action, and Result formats.

---

## 🛠️ Tech Stack

* **Frontend**: Vanilla JavaScript & Tailwind CSS (via CDN)
* **Hosting**: Vercel (Pure Static Deployment)

---

## 🚀 Quick Start / Self-Hosting

1. Clone or fork this repository.
2. Ensure you have the single **`index.html`** file in your root directory.
3. Deploy directly to **Vercel** or any static hosting provider with the Framework Preset set to **Other**.
